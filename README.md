# ESP32-S3 AMOLED Watch Firmware

Free custom firmware for the Waveshare ESP32-S3-Touch-AMOLED-2.06 watch development board.

The firmware binary is available from the **Releases** section. This repository provides the firmware, installation notes, and release information. The source code is not currently published.

## Firmware

- **Device:** Waveshare ESP32-S3-Touch-AMOLED-2.06
- **Firmware file:** `S3Watch_flash.bin`
- **Flashing tool:** ESP Flash Download Tool
- **Price:** Free
- **Source code:** Not published at this time

> Check the release notes and flashing instructions before installing. Use only firmware intended for your exact board.

## Features

The feature list will be added after it has been confirmed for the published build.

## Download

1. Open **Releases**.
2. Choose the latest release.
3. Download `S3Watch_flash.bin` from its **Assets** section.
4. Follow the [flashing instructions](docs/FLASHING.md).

If there is no release yet, the firmware has not been published here.

## Installation

See [Flashing instructions](docs/FLASHING.md).

**Important:** The correct flash address, flash mode, and any additional settings depend on how this exact firmware binary was built. Use the settings supplied with the release. Do not guess the address or copy settings from firmware for another board.

## Compatibility

This firmware is intended for the Waveshare ESP32-S3-Touch-AMOLED-2.06 board. Compatibility with other boards or revisions is not guaranteed.
